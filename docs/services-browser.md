# Browse native service

Browse is opt-in. In Settings → Connections → Browse browser, choose an existing Chromium or Microsoft Edge executable. Saving records a path; it does not start or verify the browser. Start in Browse creates an isolated headless process and a fresh profile under this Rust app's service data root, with a loopback-only ephemeral DevTools port, downloads denied, extensions and background networking disabled. No installed browser profile, original app data, listener, or browser process is discovered or used. Stop or 15 minutes without an action closes the owned process tree and removes the profile. Live frame refresh does not extend the idle timer. On Windows, a job object kills assigned child processes when the app exits; a crash can leave the temporary profile directory behind.

The service exposes only fixed Browse calls, not arbitrary CDP or shell access. Navigate accepts HTTP(S) and `about:blank` without embedded credentials. Up to eight tabs, desktop/phone viewport, navigation/history, reload, screenshots, visible controls, click, wheel, typing, keys, fill, select and check are supported. Visible-state extraction omits password fields and input values. Manual input requires an unused recent frame from the same document; DOM actions require a matching, freshly observed snapshot. Uncertain input is not retried. The user remains responsible for the actions they perform on websites.

Ask Jev stores its separately entered key with Windows DPAPI. A key being saved means configured, not tested. Jev requests explicitly send the goal and bounded visible page text and controls to TypeSafe. It selects visible controls, passages, requested addresses, known search destinations, literal text spans and bounded scroll continuations; controls with labels indicating consequential actions are excluded. The intent extraction and confidence/source-receipt logic are an approximation and have not been verified against a live provider, so exact original advice parity is not established. Mercury uses the separately configured native Fresh ideas key, sends the goal, visible page and bounded prior moves to Inception on explicit request, and validates the proposed control, option, tab, URL and search text. Inferred destinations are limited to public HTTPS homepages; paths require a user-supplied address. Enter and controls labelled as consequential require review. This label-based review is not a complete classifier; inspect all proposed actions and results. Provider availability is checked only on a request. Neither provider was contacted during QA.

An isolated test harness exercised a real installed Edge against a loopback fixture: screenshot, fill, click, select, stale snapshot and single-use frame, phone/desktop, navigate/back/forward/reload, tab create/switch/close, and process cleanup. Local protocol tests cover provider failure without exposing the key and rejection of invented controls/options/destinations. These checks do not establish live provider compatibility, real-site compatibility, full planner parity, or UI integration. On Windows the process starts suspended, is assigned to a kill-on-close job, and only then is resumed.
