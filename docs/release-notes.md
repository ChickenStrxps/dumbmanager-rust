DumbManager Rust is a separate Windows preview with the original DumbManager
interface and ASCII artwork, native SQLite storage, configurable T3 connections,
Mercury/Jev, Discord, evidence, research and Social cards.

Run the Windows setup executable. The source ZIP contains the matching tracked
source. Each installation uses its own data folder and credentials. Existing
DumbManager and DumbAPI installations are not imported or changed.

Settings → Connections → Application updates supports signed GitHub Releases
updates. Startup checks are optional and off by default; installation requires
confirmation. The signature and manifest files are used by the updater.

Mercury/Jev connection tests, read-only T3 thread discovery and Discord
bot/application authentication passed live. End-to-end external delivery,
microphone/audio, physical phone access and Windows GIF clipboard paste remain
unverified. Installer upgrade testing is deferred for this preview. This is not
a claim of complete replacement parity. See the migration inventory in the source.
